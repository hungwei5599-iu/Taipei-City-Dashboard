# 戰略評估：台北城市儀表板核心見解 🧠

本目錄定義了專案的「決策戰略」與「開發重點」，旨在將儀表板從單純的數據展示，提升為具備行動建議的治理中樞。

## 🎯 核心轉型定位：從視覺化到自動化決策

透過對現有 172 個組件的盤點，我們發現了三個關鍵的戰略缺口，這也是本次黑客松我們必須補強的核心：

### 1. 雙城平權：終結新北市的「零組件」窘境
- **現狀**：目前生產環境 API 中，新北市（ntpc）的儀表板與組件數量為 **0**。
- **目標**：我們必須證明相同的資料規格（5 種資料格式）能無縫套用到跨縣市開放資料層。接入新北資料（如 AED、避難所）是解決平台擴張性的基礎痛點。

### 2. 決策大腦：拒絕「靜態死水」
- **現狀**：91% 的現有組件僅顯示「當下狀態」，無法追蹤趨勢或預測未來。
- **目標**：政府不需要「賣萌」的 AI 吉祥物。我們需要 AI 作為協助判斷閾值、分析災變趨勢、並產出「行動建議 (Operational Action)」的輔助工具。目標是實現**從「看得到」升級為「決得了」**。

### 3. 有溫度的空間理解：市民防護網
- **現狀**：目前的儀表板多以宏觀指標為主。
- **目標**：「溫度」立基於民生基礎與安全。將生硬的 CSV 轉化為與市民家戶距離息息相關的微觀視覺化（如：以村里為單位的資源密度、文化雷達圖），讓市民一眼看出身邊的都市韌性。

## 🚦 下一步行動定位
1. **雙城平權**：組件必須同時支援雙北資料。
2. **具備預測能力**：帶入具有歷史/趨勢軸的組件。
3. **務實的治理 AI**：AI 洞察異常並總結行動建议。
