# 2026 雙北程式設計節 — 六大主題資料集配對分析

> 資料來源：Open_Data.csv（臺北市 2,835 筆）、Open_API.csv（臺北市即時 API 13 筆）、dataList.csv（新北市 1,732 筆）
>

## SYS.01 智慧通勤

**核心問題**：雙北市民的通勤品質如何？哪些路線最壅塞？哪些區域公共運輸覆蓋不足？

### 建議組件

### 組件一：雙北公車到站即時看板

- **臺北資料集**：`臺北市預估到站時間(公車)`（CSV，即時）+ `臺北市公車車上擁擠度`（JSON，即時）
- **新北資料集**：`公車預估到站時間`（JSON/CSV/XML，每 2 分鐘更新）+ `公車路線清單`（每日更新）
- **視覺化方式**：路線地圖 + 即時到站倒數看板
- **整合方式**：以路線名稱或站牌 ID 為 key 串接雙北跨市公車路線
- **對民眾的價值**：跨雙北通勤者可一站查到公車即時資訊與擁擠程度

### 組件二：雙北交通事故趨勢分析

- **臺北資料集**：`臺北市道路交通事故按月別`（CSV，每月更新）+ `臺北市A1及A2交通事故資料`（CSV，每年）
    - 欄位：發生件數、死亡人數、受傷人數、酒後駕車、肇事地點座標
- **新北資料集**：`道路交通安全`（JSON/CSV/XML，每年）+ `每年新北市A2交通事故時間別`
- **視覺化方式**：折線圖（月趨勢）+ 散點地圖（事故斑點圖）
- **整合方式**：以月份對齊做雙北並排折線比較；事故座標疊圖
- **對民眾的價值**：辨識高風險路段與時段，供用路人與政策制定者參考

### 風險提示

- YouBike 即時資料欄位名稱雙北不同（需 mapping 對照表）
- 公車到站 API 格式差異大，臺北走 data.taipei，新北走 data.ntpc，需各自寫解析
- 交通事故：臺北有月報，新北多為年度統計，時間粒度不同需注意
- **建議優先做 YouBike 組件**，資料最乾淨、更新最頻繁、雙北格式最接近

## SYS.02 韌性防災

**核心問題**：雙北地區防災資源是否充足？哪些區域淹水風險最高？災害發生時民眾如何快速找到避難點？

### 建議組件

### 組件一：雙北避難收容所地圖

- **臺北資料集**：`臺北市○○區各里簡易疏散避難地圖資訊`（CSV，各區分開，共 12 區）
    - 欄位：District、Village、FILE_URL
- **新北資料集**：`新北市避難收容處所一覽表`（JSON/CSV/XML，每年更新）
- **視覺化方式**：互動地圖（Mapbox），點擊顯示收容量與聯絡資訊
- **整合方式**：臺北需合併 12 區資料並 geocoding；新北已有結構化清單，統一格式後疊圖
- **對民眾的價值**：災害來臨時快速找到最近避難所，了解各區收容量是否足夠

### 組件二：雙北即時水情監測儀表板

- **臺北資料集（API）**：
    - `臺北市河川水位即時資料`（即時 10 分鐘）
    - `臺北市水利處雨量站即時資料`（即時 10 分鐘）
    - `臺北市水利處雨水下水道水位站即時資料`（即時 10 分鐘）
- **新北資料集**：`新北市各抽水站資訊`（每年）+ `新北市十大低漥地區`（每年）+ `新北市颱風期間各型移動式抽水機佈設資訊`（每年）
- **視覺化方式**：即時水位折線圖 + 雨量柱狀圖 + 低漥區域標示地圖
- **整合方式**：臺北即時 API 輪詢 + 新北靜態風險標示，雙圖聯動
- **對民眾的價值**：颱風豪雨期間即時掌握水情，判斷是否需要疏散

### 組件三：雙北火災統計趨勢

- **臺北資料集**：`臺北市火災資料統計月報表`（CSV，每月）+ `臺北市火災起火原因及損失情形`（CSV，每年）
    - 欄位：行政區、火災次數、分類、起火時段、起火原因
- **新北資料集**：`義消人數及火災死傷人數`（JSON/CSV/XML，每年）+ `遭受災害救助情形`（每年）
- **視覺化方式**：堆疊長條圖（起火原因）+ 雙北對比折線圖（年度趨勢）
- **整合方式**：年度資料對齊比較，臺北月報可額外做季節分析
- **對民眾的價值**：了解火災高風險原因與時段，提升居家防火意識

### 風險提示

- 臺北避難資料分散在 12 區獨立資料集，需合併且部分只有圖檔連結（需確認是否有座標）
- 新北水情缺乏即時 API，只有靜態風險資料，雙北水情即時性不對稱
- 臺北即時 API 需注意 rate limit 與 API key 設定
- **建議優先做避難收容所地圖**，雙北都有資料且視覺衝擊力強

## SYS.03 永續環境

**核心問題**：雙北空氣品質差異多大？垃圾回收率誰領先？再生能源推動進度如何？

### 建議組件

### 組件一：雙北空氣品質即時 vs 歷史比較

- **臺北資料集**：`臺北市環境空氣品質監測結果月報表`（CSV，每月）
    - 欄位：PM2.5、二氧化硫、一氧化碳、二氧化氮、臭氧
- **臺北 API**：`臺北市水質監測資訊`（JSON，每 15 分鐘，可輔助環境面向）
- **新北資料集**：`新北市空氣品質資訊`（JSON/CSV/XML，**每小時**更新）+ `新北市空氣品質人工監測站位置`（每年）
- **視覺化方式**：折線圖（PM2.5 月趨勢雙北對比）+ 測站地圖（AQI 色標）
- **整合方式**：以月份為 key 做雙北 PM2.5 並排折線圖；測站座標疊圖
- **對民眾的價值**：敏感族群可掌握雙北空品差異，選擇活動區域

### 組件二：雙北垃圾清運與回收地圖

- **臺北資料集**：`臺北市垃圾車點位路線資訊`（CSV）+ `臺北市各區清潔隊資源回收量`（CSV）
    - 欄位：行政區、里別、路線、抵達時間、緯度、經度、回收量
- **新北資料集**：`新北市垃圾車路線`（JSON/CSV/XML，**每日**更新）+ `新北市黃金資收站資訊`（KML/JSON）
- **視覺化方式**：動態路線地圖（垃圾車追蹤）+ 各區回收量長條圖
- **整合方式**：垃圾車路線座標統一格式疊圖；回收量以行政區做雙北對比
- **對民眾的價值**：不再追垃圾車！即時掌握路線與到達時間

### 組件三：雙北再生能源發展追蹤

- **臺北資料集**：`臺北市再生能源發電設備之核准資料`（CSV，每 6 月）
    - 欄位：同意備案件數、裝置容量
- **新北資料集**：（缺乏直接對應資料集，`新北市八里垃圾焚化廠營運管理` 可做替代參考）
- **視覺化方式**：年度折線圖（裝置容量成長）+ 圓餅圖（能源類型占比）
- **整合方式**：新北缺乏完全對應的再生能源統計，需從焚化廠發電量間接推算
- **對民眾的價值**：追蹤綠能進展，了解雙北能源轉型速度

### 風險提示

- 空品資料：臺北為月報，新北每小時更新，粒度差異大但對趨勢分析影響不大
- 垃圾車路線：雙北格式差異大，需各自解析再統一
- 再生能源：**新北缺乏直接對應資料集**，建議改用環保署全國再生能源統計做補充（需額外找資料源）
- **建議優先做空品比較組件**，資料最完整且更新頻率高

## SYS.04 食安健康

**核心問題**：雙北食品安全稽查涵蓋率如何？AED 急救設備分布是否足夠？醫療資源是否均衡？

### 建議組件

### 組件一：運動中心使用情況

- **臺北資料集**：`臺北市各區運動中心`、`臺北市各運動中心場地開放使用情形`（需尋找即時人數API）
- **新北資料集**：新北市國民運動中心相關資料（如設施、即時人數等，待確認API）
- **視覺化方式**：Mapbox 點位地圖 + 即時設施儀表板（各館人數、冷氣、停車位、可用設施如游泳池/羽球場）
- **整合方式**：整合雙北運動中心的靜態設施清單與動態即時人數 API 進行疊圖
- **對民眾的價值**：針對想要運動的族群，能馬上知道哪間中心有自己需要的器材與設施，且目前人數是否壅塞

### 組件二：雙北醫院急診室人數

- **臺北資料集**：`臺北市食品衛生管理工作`（CSV，每年）+ `臺北市食品衛生管理查驗工作`（CSV，每年）
    - 欄位：稽查家次、查驗件數、不符規定比率
- **新北資料集**：`食品業者登錄數`（JSON/CSV/XML，每季）+ `市售食品標示合格率`（每季）+ `新北市食品抽驗資料`（每月）
- **視覺化方式**：雙軸折線圖（稽查量 vs 不合格率）+ 年度對比長條圖
- **整合方式**：以年度為 key 做雙北稽查家次與不合格率對比
- **對民眾的價值**：了解雙北食安把關力度，消費時更安心

### 風險提示

- AED 資料品質佳，雙北都有座標，是最安全的選擇
- 食安資料：臺北以年度統計為主，新北有月/季更新的抽驗資料，粒度不同
- 醫院資料：臺北有詳細病床數，新北主要是院所名冊，欄位深度不對稱
- **建議優先做 AED 地圖**，資料最乾淨、雙北格式最接近、民眾感知度高

## SYS.05 勞動福祉

**核心問題**：雙北就業市場健不健康？長照托育資源是否足夠？弱勢族群保障如何？

### 建議組件

### 組件一：雙北托育資源供需分析

- **臺北資料集**：`臺北市嬰幼兒照顧服務_公辦民營托嬰中心`（CSV）+ `臺北市嬰幼兒照顧服務_私立托嬰中心`（CSV）+ `臺北市托嬰中心收托人數`（CSV）
    - 欄位：機構名稱、收托人數、地址
- **新北資料集**：`新北市私立托嬰機構名冊`（JSON/CSV/XML，每年）+ `托育機構概況`（每年）+ `新北市政府社會局委託辦理居家托育服務中心名冊`（每年）
- **視覺化方式**：行政區長條圖（供給 vs 需求）+ 點位地圖
- **整合方式**：統計各區托嬰機構數與可收托人數，結合出生率做供需比
- **對民眾的價值**：新手爸媽快速掌握附近托育資源與排隊狀況

### 組件二：雙北弱勢族群保障概覽

- **臺北資料集**：`臺北市低收、中低收入戶服務_平價住宅`（CSV）+ `臺北市執行定額進用身心障礙者概況表`（CSV，每年）+ `臺北市辦理身心障礙者促進就業業務概況表`（CSV）
- **新北資料集**：`低收入戶人數及生活扶助`（JSON/CSV/XML，每年）+ `中低收入戶人數及生活扶助`（每年）+ `身心障礙`（每年）+ `中低收入老人生活津貼與老農津貼`（每年）
- **視覺化方式**：雙北並排長條圖（低收入戶率）+ 年度趨勢折線
- **整合方式**：以年度為 key，低收入戶數 ÷ 總人口 = 低收入戶率，雙北對比
- **對民眾的價值**：檢視社會安全網的涵蓋範圍，是否有弱勢被遺漏

### **組件三：雙北親子探索 「帶小孩出門不踩雷」**

整合親子館、公園遊具、兒童課程、哺乳室，爸媽快速找去處

- **誰會玩：** 0-12 歲小孩的家長
- **核心互動：** 年齡層篩選 → 設施密度 DistrictChart → AI 組合半日遊路線 → 雙北 BarChart 比較
- **雙北連結：** 台北 13 間親子館(室內強) vs 新北大量特色公園(戶外強)
- **資料源：** data.taipei/data.ntpc 親子館、公園、哺乳室、無障礙設施

### 風險提示

- 長照資料：臺北以醫院列表為主缺乏統計量，新北有機構家數統計，需補充臺北的機構清單
- 托育資料：雙北都有機構清單但缺少「等候人數」等需求面資料
- 弱勢統計：新北有整理好的年度統計，臺北較分散需合併多份資料集
- 就業/失業率：臺北有求職求才數據，新北有失業率分年齡/教育程度，指標不同但可互補
- **建議優先做長照機構地圖**，高齡議題受評審青睞，且雙北資料可配對

## SYS.06 文化共融

**核心問題**：雙北文化資源分布是否均衡？在地特色如何透過數據被看見？觀光資源如何跨市整合？

### 建議組件

### 組件一：雙北文化資產地圖

白晝之夜、北美館

- **臺北資料集**：`臺北市文化資產`（CSV）
    - 欄位：個案名稱、資產類別、資產種類、所在地理區域
- **新北資料集**：`新北市文化資產`（JSON/CSV/XML/KML，每年）+ `補助私有文化資產一覽表`（每年）
- **視覺化方式**：互動地圖（不同圖標區分古蹟/歷史建築/文化景觀）+ 分類統計圓餅圖
- **整合方式**：統一分類欄位後疊圖呈現，計算各區文化資產密度
- **對民眾的價值**：發掘住家附近的文化瑰寶，推廣在地文化認同

### 組件二：雙北藝文活動日曆

- **臺北資料集**：`臺北市政府文化局文化快遞資訊`（CSV，每 6 月）+ `臺北市立美術館展覽資訊`（CSV，每 3 月）+ `臺北市藝文推廣處各場館開放時間`（CSV）
    - 欄位：Category、StartDate、EndDate、TicketType、TicketPrice
- **新北資料集**：`新北市政府文化局藝文活動`（JSON/CSV/XML，**每日**更新）+ `新北市藝遊`（每年）+ `新北市演藝團體一覽表`（每年）
- **視覺化方式**：月曆/時間軸視圖 + 地圖標示活動地點 + 類別篩選器
- **整合方式**：統一日期格式後合併為雙北活動日曆，可按區域/類別篩選
- **對民眾的價值**：一站式瀏覽雙北藝文活動，不再錯過好展覽

### 組件三：雙北觀光遊憩熱度分析

- **臺北資料集**：`臺北市觀光遊憩按月別`（CSV，每月）+ `臺北旅遊網景點資料(中文)`（CSV）
    - 欄位：各景點月參觀人次
- **臺北 API**：`景點統計資料`（每月更新）
- **新北資料集**：`新北市觀光旅遊景點`（JSON/CSV/XML）+ `觀光服務人員`（每年）+ `新北市旅遊服務中心資訊`
- **視覺化方式**：雙北景點熱力圖 + 月度遊客量折線圖（季節趨勢）
- **整合方式**：臺北有月度人次，新北有景點清單，可做空間分布對比
- **對民眾的價值**：規劃假日出遊避開人潮，發掘冷門但精彩的景點

### 風險提示

- 文化資產資料品質佳，雙北都有分類與座標，配對容易
- 藝文活動：新北每日更新很棒，臺北更新較慢（每 3-6 月），時效性不對稱
- 觀光：臺北有詳細月度人次，新北缺乏對等的遊客量統計，對比深度有限
- 新北 `博物館家族清單` 和 `立博物館群` 可補充博物館面向
- **建議優先做文化資產地圖**，資料最完整、雙北格式一致、視覺效果好
