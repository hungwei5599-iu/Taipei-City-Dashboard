## 組件二：避難收容缺口分析

### 基本資訊

| 項目 | 內容 |
| --- | --- |
| **資料表名稱** | `hackathon_component_8_shelter_gap_ready` |
| **主題名稱** | 避難收容缺口分析（65 歲以上脆弱族群） |
| **組件類型** | 圖表（Chart） |
| **資料範圍** | 台北市 12 區 + 新北市 9 區，共 21 筆 |
| **資料來源** | data.taipei + data.ntpc（避難所 + 人口統計） |
| **更新方式** | replace（每次執行全量覆蓋） |
| **建議前端圖表** | `BarChart`（缺口數量）+ `DistrictChart`（行政區分布） |

### 欄位清單

| 欄位名稱 | 型別 | 說明 | 範例值 | 備註 |
| --- | --- | --- | --- | --- |
| `data_time` | `TEXT` (timestamptz) | 資料擷取時間 | `2026-04-22T17:21:10+08:00` | 帶時區 ISO 8601 |
| `city_scope` | `TEXT` | 城市範圍 | `Taipei` / `NewTaipei` | 篩選用，僅兩個值 |
| `district_name` | `TEXT` | 行政區名稱 | `中山區` | X 軸標籤 |
| `shelter_count` | `INT` | 避難所數量 | `37` | 輔助資訊 |
| `shelter_capacity` | `INT` | 避難所總容量（人） | `42741` | 圖表數值 |
| `vulnerable_population_65p` | `INT` | 65 歲以上人口數 | `53876` | 圖表數值 |
| `capacity_gap_abs` | `INT` | 容量缺口（人）= 人口 − 容量 | `11135` | 負值代表有餘裕 |
| `capacity_gap_ratio` | `FLOAT` | 缺口比率（0~1） | `0.2067` | 負值代表有餘裕 |
| `support_status` | `TEXT` | 容量狀態分類 | `gap` | 見下方值域說明 |
| `source_trace` | `TEXT` | 資料來源說明 | `data.taipei（收容處所 + 人口統計）` | 固定值 |
| `data_mode` | `TEXT` | 資料模式 | `real` | 固定值 `real` |

### `support_status` 值域對照

| 值 | 中文說明 | 判斷條件 | 建議顯示顏色 |
| --- | --- | --- | --- |
| `surplus` | 容量充足（有餘裕） | `capacity_gap_abs < 0` | `#27AE60`（綠） |
| `gap` | 輕度不足 | `0 ≤ capacity_gap_ratio < 0.5` | `#F39C12`（橘） |
| `critical_gap` | 嚴重不足 | `capacity_gap_ratio ≥ 0.5` | `#E74C3C`（紅） |

> ⚠️ 目前新北市部分行政區 `shelter_capacity = 0`（尚無登錄資料），`capacity_gap_ratio = 1.0`，一律歸類為 `critical_gap`，前端可考慮特殊標示。
> 
- C1 目前無 `wkb_geometry` 欄位，地圖座標使用 `longitude` / `latitude` 浮點欄位，前端需自行組成 GeoJSON feature。
- C8 無地理欄位，行政區地圖需前端自備行政區 GeoJSON，以 `district_name` 做 join
