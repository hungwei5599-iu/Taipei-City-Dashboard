📐 系統整體架構（一句話概念）

整個系統就像一個「城市資料中心」：資料工程負責蒐集原始資料，後端負責整理和提供資料，前端負責把資料畫成漂亮的圖表和地圖給市民看。

部分 技術 一句話說明
🖥️ 前端 Vue 3 使用者看到的畫面，負責顯示圖表和地圖
⚙️ 後端 Go + Gin 資料的中間人，接收請求、查資料庫、回傳結果
🗄️ 資料庫 PostgreSQL 永久儲存所有資料的地方，像一個超大的 Excel
⚡ Redis Redis 超快的暫存記憶體，負責防止被濫用（限流）
🔐 認證 JWT + OAuth 身份證系統，確認「你是誰」和「你能做什麼」
🔄 資料工程 Airflow 自動化的資料搬運工，定時抓取並清理外部資料
🤖 AI LLM + Qdrant 智慧助手，可以用自然語言查詢圖表和城市資料
