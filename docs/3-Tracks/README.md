# Taipei Dashdorad Hackathon Prep

This folder turns the hackathon idea into a staged preparation funnel:

1. **Topic legitimacy**
   - real public problem
   - dual-city value
   - official/open sources
   - not a demo gimmick

2. **Data-to-decision fit**
   - real datasets
   - joinable fields
   - clear government decision scenario
   - charts that still work without AI

3. **Judge readiness**
   - one-page summary
   - demo script
   - judge Q&A
   - GitHub issue/spec
   - PR wedge

## Current recommendation
- **Primary topic:** Heat island + vulnerable groups
- **Backup topic:** Disaster evacuation + shelter/material allocation
- **Stretch topic:** Elder-care + cross-district medical capacity mismatch

## Evidence already grounded
The current plan is no longer just a brainstorm. We have already found official candidate sources for:
- Taipei heat / climate adaptation context,
- Taipei and New Taipei population age structure,
- Taipei and New Taipei shelter resources,
- Taipei social care / community support proxies.
