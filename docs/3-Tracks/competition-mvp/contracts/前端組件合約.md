# 前端組件合約

最後更新：2026-05-01

Owner：林鈞元

## 規則

- 圖表只使用 ApexCharts。
- 地圖只使用 Mapbox GL。
- 每個元件都要有 Taipei / Metro-Taipei 切換。
- 每個元件都要有 loading、empty、error 狀態。
- 儀表板必須在沒有 AI 決策卡時仍可運作。
- 所有元件都必須從官方 fork 重建；不得直接複製賽前元件實作或舊原型程式碼。

## 元件

| Component | Inputs | Visual | Required behavior |
|---|---|---|---|
| 雙北現況熱區地圖 | `GET /api/v1/hackathon/mvp/map` | Mapbox symbol / circle / choropleth layer | 城市切換時同步變更點位、圖例與說明文字 |
| 趨勢與異常圖 | `GET /api/v1/hackathon/mvp/trend` | ApexCharts line 或 heatmap | 日期範圍與城市切換要更新 series |
| 臺北 vs 雙北比較卡 | `GET /api/v1/hackathon/mvp/compare` | ApexCharts bar、percent 或 compact KPI list | 不同 city scope 必須使用同一定義的指標 |
| AI 決策摘要卡 | `POST /api/v1/ai/chat/twai` | 結構化文字卡 | 顯示 source trace 與 fallback 狀態；不能阻塞基礎圖表 |

## 空狀態文案合約

- 空資料：`此篩選條件下沒有可用資料，請切換城市或日期。`
- Fallback 資料：`此區塊使用已標示的 fallback 資料，不宣稱為即時官方讀值。`
- AI 不可用：`AI 摘要暫不可用，以下圖表仍為官方資料查詢結果。`

## 完成條件

- 不可匯入 ECharts、Chart.js、D3、Recharts 或 Highcharts。
- FE 不可直接呼叫 AI API。
- 城市切換必須同時改變資料與可見文案。
- Demo 路徑在投影式儀表板畫面上仍可清楚閱讀。
