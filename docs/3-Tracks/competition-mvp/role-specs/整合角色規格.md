# 整合角色規格 / Integration Role Spec

最後更新 / Last updated: 2026-05-01

- 擁有者 / Owner: 余振言
- 任務軌 / Lane: integration / platform
- 產出物 / Artifact: local-stack verification、git audit、demo smoke evidence
- 輸入 / Input: official fork branch state、lane completion evidence、demo script and compliance checklist
- 輸出路徑 / Output path: `docs/3-Tracks/competition-mvp/verification/`
- 上游依賴 / Upstream dependency: DE、BE、FE artifacts
- 下游消費者 / Downstream consumer: PM final signoff
- 勿重複 / Do-not-duplicate: feature-lane implementation unless explicitly handed off

## 輸入 / Inputs

- official fork branch state。
- DE / BE / FE completion evidence。
- demo script 與 compliance checklist。

## 工作合約 / Work Contract

- 驗證 local stack 可以跑通 demo path。
- 檢查沒有 secrets、`.env`、`node_modules`、`venv` 或 `.venv` 被提交。
- 檢查沒有未核准的 package changes 被 staged。
- 確認 commit history 反映可驗證的實作單位。

## 完成準則 / Done Criteria

- demo smoke checklist 通過。
- git audit checklist 通過。
- 其餘風險都有寫明 owner 與下一步動作。
