# PM 角色規格 / PM Role Spec

最後更新 / Last updated: 2026-05-01

- 擁有者 / Owner: 羅浚
- 任務軌 / Lane: PM
- 產出物 / Artifact: scenario matrix、demo narrative、compliance signoff
- 輸入 / Input: official theme and rules、archive evidence、team capacity and timebox
- 輸出路徑 / Output path: `docs/3-Tracks/competition-mvp/plan/`
- 上游依賴 / Upstream dependency: official theme announcement and verified source availability
- 下游消費者 / Downstream consumer: DE、BE、FE、integration
- 勿重複 / Do-not-duplicate: DE source mapping、BE endpoint design、FE component implementation

## 輸入 / Inputs

- 官方主題與規則。
- 來自 archive 的既有來源證據。
- 團隊人力與時間盒。

## 工作合約 / Work Contract

- 選定一個主題，並保留一個 fallback。
- 讓四個 MVP 元件對應到同一個決策敘事。
- 每個 lane 都有單一 DRI。
- demo 敘事要說明 source、decision、AI boundary 與 merge-back route。

## 完成準則 / Done Criteria

- 已選定一個主題，並保留一個 fallback。
- 四個 MVP 元件都對應到同一個決策敘事。
- 每個 lane 都有單一 DRI。
- demo 敘事清楚說明 source、decision、AI boundary 與 merge-back route。
