## 輸入 / Inputs

- PM demo narrative。

## 工作合約 / Work Contract

- 使用 city switch render 四個 component。
- 圖表使用 ApexCharts，空間圖層使用 Mapbox。
- UI 要顯示 source / fallback state。
- 沒有 AI 時，核心 dashboard 仍要可用。

## 完成準則 / Done Criteria

- 四個 component 都能從 API-shaped data render。
- city switching 會改變 data 與 copy。
- AI unavailable state 不會讓 dashboard 壞掉。
- 沒有加入被禁止的 chart library 或 frontend AI provider call。
