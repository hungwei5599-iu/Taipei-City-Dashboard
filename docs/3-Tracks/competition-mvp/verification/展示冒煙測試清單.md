# 展示冒煙測試清單

最後更新：2026-05-01

## 冒煙流程

- [ ] Dashboard route 可在本機開啟。
- [ ] 捷運態勢地圖至少能渲染一個空間圖層。
- [ ] 趨勢 / 異常圖表可以渲染非空資料，或清楚顯示空狀態。
- [ ] 台北 vs 生活圈比較卡會以選定指標渲染。
- [ ] AI 決策卡會回傳結構化摘要，或顯示可見的 fallback。
- [ ] 城市切換會更新所有相關元件。
- [ ] 提示者可以看到 source / fallback 狀態。
- [ ] 5 分鐘展示腳本可以完成，而且不需要切換到投影片。

## 失敗規則

如果某個元件阻擋了 demo，就移除或隱藏那個元件，並維持其他已完成元件穩定。不要為了救 demo 失敗而新增未審查的依賴。
