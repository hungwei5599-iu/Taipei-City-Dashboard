# Scenario Matrix

Last updated: 2026-05-01

This matrix maps official theme announcements to the same 4-component MVP engine.

| Theme | User | Decision question | Evidence needed | MVP framing |
|---|---|---|---|---|
| SYS.01 Smart commute | Transport operator | Where should service or guidance be adjusted first? | spatial demand, congestion trend, cross-city comparison | Mobility pressure dashboard |
| SYS.02 Disaster resilience | Emergency planner | Which district needs support first and what side effects follow? | shelter/resource gap, hazard trigger, affected districts | Resilience priority dashboard |
| SYS.03 Sustainable environment | Environmental planner | Which areas need mitigation or resource support first? | exposure, resource coverage, trend movement | Environmental response dashboard |
| SYS.04 Food safety and health | Health bureau | Which area or facility group needs intervention first? | incident trend, facility status, district risk | Health capacity dashboard |
| SYS.05 Labor welfare | Labor bureau | Which service gap affects the most vulnerable groups? | district need, service availability, trend | Welfare service gap dashboard |
| SYS.06 Cultural inclusion | Cultural bureau | Which districts lack access or need event/resource balancing? | facility density, event distribution, cross-city gap | Cultural access dashboard |

## Selection Rule

Pick the theme with the strongest official source coverage after competition announcement. If two themes are close, choose the one that can close DE -> BE -> FE in the first data loop fastest.
