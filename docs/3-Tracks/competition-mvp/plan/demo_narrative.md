# Demo Narrative

Last updated: 2026-05-01

The dashboard is the presentation. Do not rely on a slide deck.

## Two-Minute Script

Our work turns dual-city open data into an actionable decision screen.

The map shows where the condition is concentrated. The trend chart shows whether the situation is worsening. The comparison card shows how Taipei differs from Metro Taipei. The AI decision card reads the same validated data and explains insight, risk, recommendation, and side effects.

The AI layer is explanatory, not authoritative. If the AI service is unavailable, the dashboard still shows the evidence and supports the same decision workflow.
